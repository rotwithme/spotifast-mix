Spotifast Mix 0.14.3 adds signed Windows updates from this project's GitHub releases. It keeps Spotifast's native interface and adds SoundCloud accounts, search, playlists, and the independent Local mix session.

## New

- **Update from inside the app.** New Windows builds appear in the existing update icon. Download the update and choose Restart to update. Accounts, settings, and playlists stay in place, and a failed startup restores the previous executable.
- **A one-time upgrade for earlier custom builds.** The bootstrap script upgrades the update-disabled 0.14.2 portable copy without dragging files. It waits for you to quit the app and preserves its data folder.
- **Spotify and SoundCloud in one native interface.** Search either service, manage SoundCloud likes and owned playlists, and save local mixed playlists while keeping Spotify Connect separate from Local mix.
- **Merge playlists and add songs in bulk.** Right-click a Spotify playlist to merge its complete contents into a new or existing local playlist. Selected Spotify songs and the SoundCloud and local lists' Select all controls add songs together, preserving their order and repeated entries.

## Fixed

- **Protected SoundCloud streams are authenticated.** The playback loader authenticates the API stream link, checks redirects, and fetches signed CDN audio without forwarding the account token.
